# Analisis_Clustering_menggunakan_K-Means
Analisis data gempa bumi menggunakan algoritma K-Means Clustering untuk mengelompokkan kejadian gempa berdasarkan lokasi, kedalaman, magnitudo, dan fitur lainnya. Proyek ini meliputi preprocessing data, eksplorasi data, penentuan jumlah cluster dengan Elbow Method dan Silhouette Score, serta visualisasi dan evaluasi hasil clustering.
